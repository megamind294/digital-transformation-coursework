# Digital Transformation Coursework

A documentation portfolio reconstructed from recovered Digital Transformation coursework structure: a literature-review task and a longer analysis/modeling task using UML-style diagrams.

> **Important provenance note:** the original completed essays and submitted diagrams were not recoverable from the accessible file library. The material in this repository is therefore a **portfolio reconstruction and set of study notes**. It does not claim to reproduce the exact submitted papers, citations, grades, professor feedback, or original diagrams.

## Contents

### Task 1 — Literature Review

`task-1-literature-review/` contains:

- the recovered assignment theme;
- a structured review question;
- a literature-review framework;
- concise study notes on digital-transformation drivers, technology, organization, risk, customer value, and measurement.

### Task 2 — UML / Process Modelling

`task-2-uml-case-study/` contains a newly created fictional case study showing how a manual service-request process could be transformed into a digital self-service workflow.

The Mermaid diagrams show:

- a use-case view;
- an activity/process view;
- a sequence view;
- a component/system-boundary view.

## Skills demonstrated

- Literature review structuring
- Digital transformation concepts
- Business-process analysis
- Requirements and stakeholder thinking
- UML-style modelling
- System boundaries and data flows
- Change/risk analysis
- Transparent documentation and source provenance

## Why the reconstruction is explicit

A public portfolio should distinguish recovered coursework from newly created explanatory material. Where the original source could not be verified, this repository chooses transparency rather than inventing academic metadata or pretending reconstructed prose is an untouched submission.
