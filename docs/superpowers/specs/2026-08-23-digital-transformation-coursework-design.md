# Digital Transformation Coursework Portfolio Design

## Goal
Preserve the recovered Digital Transformation coursework structure in a public, recruiter-readable repository without fabricating unavailable original essay text, grades, or submission artifacts.

## Provenance
Recovered coursework notes indicate:
- Task 1 was a literature-review assignment for the English Master's study track.
- Task 2 required a longer written analysis and UML/model diagrams.
The original completed documents were not recoverable from the accessible file library, so this repository contains **portfolio reconstructions and study notes**, not claimed original submissions.

## Contents
- `task-1-literature-review/README.md`: recovered assignment purpose plus a reconstructed literature-review framework on digital transformation.
- `task-1-literature-review/review-notes.md`: portfolio study notes covering definitions, drivers, technologies, organizational change, risks, and measurement.
- `task-2-uml-case-study/README.md`: a newly created case study explicitly marked as reconstruction.
- `task-2-uml-case-study/diagrams.md`: Mermaid UML-style use-case, activity, sequence, and component diagrams.
- `references.md`: categories of sources to consult; no fake bibliography entries.

## Reconstruction Case Study
Use a fictional service company modernizing a manual customer-request workflow into a digital self-service platform. This avoids publishing proprietary or personal data while demonstrating process modelling.

## Quality Rules
- Never claim reconstructed prose is the exact submitted essay.
- Do not invent citations, bibliography entries, grades, professor feedback, or submission metadata.
- Diagrams must be clearly identified as newly created portfolio visuals.
- Keep the repository documentation-focused; no unnecessary software stack.

## Success Criteria
The repo accurately communicates the recovered coursework scope, includes useful literature-review structure and UML-style modelling, and is transparent about reconstructed versus original material.
